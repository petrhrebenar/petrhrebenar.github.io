# petrhrebenar.github.io

Personal academic website of Petr Hrebenár. Plain static HTML served by GitHub Pages.

- `index.html` home page
- `research.html` publications and conference presentations
- `cv.pdf` CV (linked from the home page)
- `style.css`, `fonts/` (Latin Modern Roman, self-hosted), `icons/`

Layout adapted from the site of Josef Montag.
